# v1.2 无类别词数据人工抽检（第 1 轮）

- **样本来源**：生成的第一块数据，1,088 张图，经过 `catfree_build.py` 过滤之后，每个题型随机抽 8 条（seed 7）。
- **渲染方式**：`scripts/v12/render_check.py`。绿框是目标，蓝框是关系锚点；负例只画锚点，"不存在"直接对着原图判断。
- **判定方式**：我逐张看图判定。

**结果：53/56 = 94.6%，没有低于 6/8 的题型。** 达到"≥ 90%、单题型不低于 6/8"的门槛。

| 题型 | 结果 | 错例与说明 |
|---|---|---|
| cf_func（纯功能正例） | 7/8 | ✗ #6 "what I could ride to get around"：目标是画面底部被截断的火车，但背景里还有没标注的汽车，有歧义 |
| cf_generic（泛称正例） | 8/8 | #0 "the furniture over there" 指滑板场里的 bench，标注是 bench，判为对，但说法偏勉强 |
| cf_rel（关系正例） | 7/8 | ✗ #4 "床上放着的那个东西"：床上除了玩偶，还有一支没标注的笔，"东西"有歧义 |
| cf_func_neg（功能负例） | 8/8 | 多为远类别（剪纸、烤面包），属于偏易的负例 |
| cf_generic_neg（泛称负例） | 8/8 | #7 "有啥吃的吗" 是问句形式，但判定正确 |
| cf_rel_neg（关系负例） | 7/8 | ✗ #3 "那个人头顶上的东西"：人出现在后视镜的倒影里，"头顶上"可以指镜子或车身，有歧义 |
| cf_anchor（规则生成的一致性锚点） | 8/8 | |

三个错例都不是规则答案算错了，而是图里存在**没有标注的物体**或**指代含糊**，验证模型没有拦住。泛称"东西 / thing"最容易出这类问题。

逐条记录（image_id 和文本）见同目录下的 `spotcheck_catfree_samples.json`。
