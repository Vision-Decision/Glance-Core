# Glance v1.2 验收结果（对照 PREREG）

**结论：25 条预注册标准里，16 条通过，9 条未通过。**

- **全部通过**：A 组（描述偏移）、B 组（Glance-Data 诊断）。v1.1 的四个主要毛病都修好了。
- **有退步**：自然图像的传统指标（RefCOCO、gRefCOCO 的拒答和校准）低于 v1.1，没有守住；VenusBench 在 S2 官方口径下的接受率和 GREC 官方指标也没达标。
- **守住了**：GUI 和文本决策。VenusBench、ScreenSpot-v2、ScreenSpot-Pro 都比 v1.1 略好。

- **检查点**：HF `Vision-Decision/glance-train-ckpts` 的 `v1.2/ckpt_final.pt`（3800 步，从 v1.1 起训），只评这一个最终检查点。

  - S2 流水线在 G4 上也用原生分辨率。

## 退步从哪来，以及修复方案（不在本版的评测集上回调）

详细分析见 `regression_diagnosis.md`。以下是逐条配对比较的结论。

**1. RefCOCO −1.5。** 掉分的条目里，80% 是框错了，而不是拒答；最差的是长表达，以及带锚点的关系句，比如 "guy left of umbrella"。

- 原因：人写表达的回放只剩 v1.1 的 36%。新增的自然图像数据有四分之三是模板或 LLM 写的句子，其中的关系句是"泛称 + 关系 + 有名字的锚点"，结构和 RefCOCO 相反。
- v1.3 的修复：RefCOCO 回放恢复到 22 万；多实例的裸类别（cat_all）以"只监督存在"的方式放回训练。

**2. gRefCOCO N-acc −2.2，GREC 官方 N-acc −1.8。** 退步全是"无目标被判为有"，集中在短的"方位词 + 名词"，比如 "suitcase on the left side"、"left seat"。

- 原因：`pos_pos_sole` 只配了"同一物体在另一侧"这一种负例，缺少"方位词 + 图里不存在的类别"这种负例；另外，短的泛称正例相对负例太多（3.4:1）。
- v1.3 的修复：补上这类负例，并把泛称正负例比例降到 1.5:1。

**3. 关系说法的 N-acc −16。** 训练里没有"这个类不存在 + 关系"的负例，而以"东西 / thing"开头的关系句在训练中永远是正例。

- v1.3 的修复：补上这类负例，关系句正负例做到 1:1。

**4. 中文 −5.3。** 多属性的中文长句被拒了，比如"坐在绿色沙发上的一个男的"。中文难负例约 4.5 万，中文长正例只有约 1.9 万。

- v1.3 的修复：把 RefCOCO train 翻译成中文，作为长正例，并和英文原句组成一致性组；中文难负例和长正例按 1:1 配比。

**5. VenusBench 有目标时的接受率只有 60%（D3）。** 比 v1 的 53.5% 好一些，但 GUI 上的过度拒答仍然存在。S2 拿 GUI 数据拟合 Platt 之后，接受率能到 72.7%，但拒答率会跌到 70.4%。

- 这一项需要在 GUI 数据上做"存在 / 不存在"的平衡，不是本版数据能解决的。
- v1.3 的建议：GUI 负例维持 10%；从 S1 推荐的推理类、功能类 GUI 指令里补正例。

以上改动都是对数据配比的修复建议，均未使用本版评测集上的结果反向调参。
