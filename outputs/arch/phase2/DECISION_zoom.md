# 第二阶段决策记录：训练"原生块内 zoom"这一步

2026-11-19 训练前写定，结果出来后追加。

## 为什么做
- 实验 2（免训练）：在 ScreenSpot-Pro 全量 1,581 题上，粗定位第一遍得 50.1。把裁剪图放进问题块（layout `pre`，裁剪 token 能看到整图前缀）得 57.4，比另起一次 prefill 只看裁剪图的基线（60.7）低 3.2 [1.6, 4.7]。
- 在 1/5 子集（317 题）上，把整图 token 从块内所有 token 的注意力里屏蔽掉（layout `pre_alliso`；GDN 状态仍然带着整图），零训练就能到 **65.6**，基线 62.1，`pre` 60.9。全量结果在跑。
- 由此推断：块内 zoom 的问题出在分布外，不是信息不够。头从没见过"裁剪 token 跟在整图后面"这种排列。屏蔽注意力之后，裁剪 token 的表示又回到了"单图"的分布里，同时 GDN 状态还携带整图的粗略上下文，所以效果反而比单独 prefill 好。训练应该能进一步把这部分差距收回来。

## 做什么
从 v1.1（LoRA + 头）续训 800 步。每一步包含：
1. 一个 zoom micro-batch：GUI 记录，全图作为共享前缀（≤2048 token）。每题一个块内裁剪：取屏幕每边的 0.2–0.33，中心在目标附近抖动 ±35%，≤1024 token，最多放大 2 倍。在 `alliso` layout 下，只用裁剪 token 计算框损失，坐标取裁剪坐标系。
2. 一个 v1.1 混合数据的回放 micro-batch，用标准损失，目的是保住第一遍和类型化头。

学习率：LoRA 1e-4，头 2e-4，cosine，warmup 50 步。

## 预注册判定标准
- **主指标**：SS-Pro 原生，用块内 zoom（alliso）。要比零训练的 alliso 全量结果高 ≥ 2 点，配对 bootstrap CI 不跨 0。
- **护栏**：第一遍 SS-Pro 原生不低于 v1.1 超过 1 点；RefCOCO testA/testB 不低于 v1.1 超过 1 点；gRefCOCO N-acc 不低于 v1.1 超过 2 点。
- 训练时裁剪位置是模拟的。如果测试时第一遍的落点分布和训练时差得多，就把 jitter 改成真实第一遍的误差分布，作为第二个版本。

## Z1 结果（2026-11-19）：未通过
- 全量零训练 alliso：SS-Pro 原生 **61.8**。第一遍 50.1，另起 prefill 的基线 60.7（`outputs/arch/zoom/`）。块内 alliso 比另起 prefill 高 **+1.1**，而且不需要再算一遍前缀。
- Z1（LoRA + 头，800 步）：第一遍降到 48.9（−1.2），块内 alliso zoom 59.3，比零训练低 **−2.5**，判定标准不通过。
- 推断：实验 1 已经说明，LoRA 增量越大，GUI 能力损失越多。拿 GUI 数据继续训 LoRA 只会让遗忘更严重，第一遍下降就是信号。所以 zoom 这一步应该**只训头**。

## Z2（结果出来之前写定）：只训头、α = 0.5、600 步
- 依据：实验 1 + 实验 2 的零训练组合（α = 0.5 + 块内 alliso）已经达到 **68.75**，另起 prefill 为 68.4。Z2 冻结骨干，只训练头去适应"裁剪在块内"的输入分布，因此不会增加遗忘。
- 判定标准：SS-Pro 原生 α = 0.5 下块内 alliso zoom 要比 68.75 高 ≥ 2 点，配对 CI 不跨 0；同时第一遍不能低于 α = 0.5 的零训练第一遍（57.8）超过 1 点。
- COCO 不受影响：α 只用在 GUI 输入上（按输入类型选 α），自然图仍然走 α = 1 的路径。头在两条路径之间是共享的，所以 RefCOCO 仍然要在 α = 1 下检查。

## Z2 结果：未通过
- 只训头、α = 0.5、训练 600 步。第一遍 57.0，零训练为 57.8；块内 alliso zoom 68.2，零训练为 68.75；另起 prefill 67.6。比零训练低 −0.6，没有达到 +2 的标准。
- 结论：在当前的裁剪模拟下，块内 zoom 训练不论动不动 LoRA 都没有收益。zoom 这一步保留零训练配方：GUI 路径 α = 0.5，块内 alliso 裁剪。
- 推断剩余误差的来源：第一遍裁剪没把目标框进来的约占 22%（α = 1 时 gt_in_crop = 0.78）。这部分训练改变不了，应当改走多候选裁剪：在共享前缀上同时开 K 个块，用存在门控挑一个。已在跑（`--cands 3`）。
- 检查点：`Vision-Decision/glance-train-ckpts:arch/{Z1_zoom_alliso,Z2_heads_a0.5}/`，评测结果在 `Vision-Decision/glance-train-data:arch/phase2/*/eval`。
