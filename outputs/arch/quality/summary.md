# Exp 3：从边分布直接解析框质量（免训练）——否定

**结论：不成立。** 把 Cramér 训练出的四条边分布（和中心 softmax）当作对真框的预测分布，解析算出 E[IoU] 和 P(IoU≥0.5)，区分好框和坏框的 AUROC 只有 **77.0**。学到的 IoU 头 κ̂ 是 **91.6**，AR + 训练 IoU 头是 **88.9**。在 κ̂ 之外再加解析量也没有增量（组合 91.6）。所以"质量从框输出本身得来、AR 学不来"这条结论**不能用**，κ̂ 依然是正确的设计。

## 设定
- 模型：受控消融的 `ours_neg25`（`Vision-Decision/glance-train-ckpts-legacy:ablation/ours_neg25_bf16.pt`），和 `ablation_v3/ar_iou` 用的是同一个模型、同一个测试集、同一套协议。
- 测试集：gRefCOCO val merged，10,834 条单目标、有框的样本（AUROC 用这些），另有 8,905 条无目标样本（双旋钮代价用）。
- 对齐检查：重跑的 κ̂ 和 ĝ 与 `outputs/ablation_v3/ar_iou/items.npz` 逐条一致（最大绝对差 0.0），IoU≥0.5 的标签一致率 99.995%。对照组的 91.6 和 88.9 都精确复现了。
- 解析量（`arch/quality/edgeq.py`，MC 采样 512 次，零训练）：
  - `edge`：只在 argmax patch 上采样四条边；
  - `mix`：在 top-32 个 patch 上按中心概率混合，每个 patch 用它自己的边分布；
  - `mixfull`：mix 再乘上 top-32 的中心质量，其余质量算作没命中。
  - 另外还做了温度 0.5 / 2 两个版本，以及中心熵、边熵、top-1 中心概率。
- CI：按图像做 1000 次 bootstrap；差值是配对的。

## 结果（`results.json` → `box_quality_present_test`）

| 质量分数 | AUROC [95% CI] | 相对 κ̂ | ECE（原始） |
|---|---|---|---|
| κ̂（学到的 IoU 头） | **91.6** [89.9, 93.4] | — | 1.31 |
| AR + IoU 头（heldout_full） | 88.9 [87.0, 90.7] | −2.8 | 0.64 |
| 解析 P50_mix | 77.0 [74.2, 79.8] | −14.6 | 10.3 |
| 解析 E_mix（温度 0.5） | 77.9 [75.3, 80.7] | −13.7 | 23.4 |
| 解析 P50_edge | 72.8 [70.2, 75.7] | −18.8 | 11.1 |
| 中心熵取负 / 边熵取负 | 63.2 / 64.6 | | |
| top-1 中心概率 | 49.6 | | |
| 边和中心统计量上的交叉拟合 LR（GFLv2 DGQP 式，需要学习） | 82.9 [80.3, 85.4] | −8.7 | |
| κ̂ + 解析量（交叉拟合 LR） | 91.6 | ±0.0 | |

v1.1 上结论相同：gRefCOCO val merged 单目标样本上，κ̂ 90.3，P50_mix 73.1（`v1.1_box_quality_present`）。

**双旋钮代价**（×100，c_H = c_R = 1）：
- c_W = 1 时，P1 协议下 κ̂ 9.16，换成 P50_mix 后 9.26（+0.10 [0.01, 0.20]）。
- c_W = 5 时，P1 下 κ̂ 14.06，P50_mix 16.68（+2.62 [1.89, 3.39]）。P2 下差距是 +4.61。
- 解析量甚至比 AR + 头还差：P2、c_W = 5 时差 +2.71 [1.61, 3.72]。

## 为什么不行（推断）
- 边的训练目标是固定 σ（1 个 bin）的高斯平滑。分布宽度基本被训练目标钉死，锐度里没剩多少关于这个样本的信息。
- 坏框的主要来源是"框错了物体"，不是"边没对齐"。中心目标把质量摊在整个 GT 框覆盖的所有 patch 上，所以 top-1 中心概率反映的是目标大小，而不是置信度：它的 AUROC 是 49.6。
- κ̂ 直接用 BCE 学 1[IoU≥0.5]，能读到隐状态里的"是不是这个物体"信息。

## 对计划的影响
- 报告里的"质量从框输出本身得来"**撤下**。"κ̂ 与 AR + 头打平"的表述不变：κ̂ 的 AUROC 比 AR + 头高 2.8，但双旋钮代价差异不显著。
- 如果要让边分布带上质量信息，需要改训练目标（例如 DFL / 可学习的 σ），属于 phase 2 的事情，优先级低。
