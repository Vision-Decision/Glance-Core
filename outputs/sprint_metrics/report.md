# Sprint S6：指标与统计复盘（摘要）

结果文件都在本目录：`ablation_stats.json`、`main_stats.json`、`xdomain_extra.json`、`two_knob.json`、`side_literature.json`、`side_di_video_docs.json`，生成它们的脚本在 `scripts/`。完整报告和逐条修改建议（R1–R12）写在 2026-11-18 发给协调者的 agent 报告里，下面只列关键发现。

## 关键发现
1. **beam-4 下 4.7% 的拒答是剪枝造成的，不是 MAP 的近似。** "none" 在第一步就排不进前 4 个候选，被直接剪掉。同一批 191 个目标里，greedy-candidate MAP 拒答 40.8%；把框换成 beam-4 找到的更优框之后，MAP 拒答仍有不超过 37.7%。所以 greedy（0.60%）、beam-4（4.7%）和 MAP（≤37.7%）是**同一个模型**的三个工作点，由搜索算法决定，而不是由模型看到了什么决定。
2. **在 MAP 的覆盖率下，门控的风险更低：4 个头里有 3 个显著，AR-digits 不显著**（差值 −0.10，区间 [−0.59, +0.39]）。
3. **用配对检验比较 AURC：** 门控对 4 条 AR 阈值曲线全部显著更好，对 4 条 margin 曲线中的 2 条显著更好。改用 E-AURC（去掉各头的基础准确率）后，只有 atomic-1000 仍然显著落后。
4. **双旋钮规则（命题 1）有效：** 不在评测集上调阈值，c_W 取 1、2、5 时，实际代价分别下降 4%、13%、33%（缺席率 25%）；缺席率 5%、c_W=5 时下降 31%。所有 CI 都不含 0。c_W=0 时两条规则完全相同，与理论一致。
5. **框精度：** 门控的 Acc@0.5 显著更高（McNemar p<1e-5）；AR 头的框更紧（Acc@0.9 是 0.68–0.71，门控 0.46）。
6. **OpenDecisions：** 底座应使用作者公布的那一行（63.6 / 46.1 / 81.2）。v1 的 intelligence 是 54.8，高于作者同底座微调的 52.8。
7. **VenusBench 拒答 81.5 [78.9, 83.9]，高于所有已发表结果（最高 78.1）。** 但正样本没有经过门控，这一点要披露。同底座的生成式模型在同一脚本下只有 3.9%。
8. **公平延迟核对无误；** 把预处理时间计入后，仍快 2.3×、2.9×、4.2×。
9. **RefCOCO：** 在 ≤4B 的模型中，v0 的 8-split 平均（92.8）最高。
10. **gRefCOCO：** CRS 的 N-acc 是 89.5，高于我们，但它的 Pr 只有 56.3（拒答过度），需要如实列出。
