# guisyn-v0 (PRIVATE, research only)

Synthetic GUI-grounding data for the decision-vision box primitive (presence gate + box). Generated by
`scripts/guisyn/` in the decision-vision repo on a CPU-only Linux host.

- **desktop**: open-source Linux applications (LibreOffice Writer/Calc/Impress/Draw, GIMP, Inkscape, Krita, FreeCAD,
  KiCad pcbnew/eeschema, VSCodium, Firefox, Thunderbird, Kdenlive, Shotcut, Audacity, darktable, QGIS, Wireshark)
  under Xvfb at 1920x1080, 2560x1440, 2560x1600, 3840x2160 (and 3840x2160 at 2x UI scale), driven by random-but-safe
  interactions. Element boxes, names and roles come from the AT-SPI accessibility tree, filtered for visibility,
  occlusion (X stacking order), clipping, AT-SPI hit-testing, pixel content and duplicates.
- **web**: Playwright Chromium screenshots of public Tranco top sites (list V38GN), DPR 1 and 2, robots.txt respected,
  no form interaction. **Web screenshots are for internal research only and must not be redistributed.**
- **negatives**: `negative_hard` = descriptions of elements seen in OTHER states of the SAME app (or other viewports of the
  same site), verified absent from this screenshot's full AT-SPI tree (desktop) / visible viewport DOM (web) by exact,
  fuzzy (rapidfuzz ratio >= 80) and substring name match; `negative_easy` = from other apps.
- No ScreenSpot-v2 / ScreenSpot-Pro / VenusBench-GD image is included (dHash + thumbnail check).

## Layout (append-only shards)
`shards/{desktop,web}/{timestamp}-{NNNN}.jsonl` + `.images.tar` (images at `images/{source}/{id}.webp`, lossless
WebP) + `.a11y.tar` (`{id}.json.gz`: full AT-SPI tree + X stacking order, or DOM elements + visible texts + page HTML).

Record: `{image, W, H, source, app, url, questions: [{text, present, box [x1,y1,x2,y2] px | null,
kind: name|function|position|icon|negative_hard|negative_easy, meta}], uncaptioned: [{box, role}], a11y, meta}`.
`uncaptioned` = icon-like elements without an accessible name (to be captioned later; not used as questions).
Convert to the decision-vision v1 pool format with `scripts/guisyn/to_v1.py`.
`stats.json` has per-app counts.
